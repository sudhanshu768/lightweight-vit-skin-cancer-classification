# Lightweight Vision Transformers for Skin Cancer Classification

## Objective
Develop lightweight Vision Transformer models for melanoma classification using imbalance-aware learning.

## Dataset
HAM10000 Dataset

## Models
- MobileViT
- TinyViT
- EfficientViT

## Features
- Cost-sensitive learning
- Attention visualization
- Efficiency analysis

## Workflow
Dataset Analysis → Baseline Training → Imbalance Learning → Attention Analysis → Efficiency Comparison
